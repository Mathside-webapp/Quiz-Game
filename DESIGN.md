# Quiz Game Library — approved reference implementation

Direction: the user-supplied illustrated galaxy, navy backgrounds, cyan planet horizons, violet frames and glossy yellow actions. The latest instruction authorizes asset creation followed by implementation.

Palette: cosmic navy #080D39, nebula purple #7555DD, starlight cyan #62DDF6, solar yellow #FFD65A, cloud white #F7FAFF. Native system typography keeps the site self-contained; variable text remains HTML.

Screens: landing, dashboard, game library and detail dialogs, quiz library, quiz editor, teacher rehearsal, results, settings, account availability dialog. Mobile collapses the navigation into an explicit Menu button and cards into one column. Forms retain visible labels, dialogs use native modal behavior, and controls have keyboard focus rings.

The illustration set consists of five separately generated PNG originals: universe background, three game covers, and a transparent app emblem. No montage was sliced into assets. The wordmark and buttons remain live HTML/CSS. Additional mascot, station, logo variants, layered planet and portal assets from the larger master brief are not included in this first preview.

The reference's playable game buttons are intentionally replaced with Coming soon / Explore because no approved game mechanics were supplied. The demonstration supports a clearly labeled quiz rehearsal, not a racing, siege or tug engine.

Future production stage: Supabase Auth, PostgreSQL owner-scoped quiz persistence, private Storage, authorized Realtime sessions, additional question formats and mathematics rendering. None of these integrations is claimed by the local preview.
